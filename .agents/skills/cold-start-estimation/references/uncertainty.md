# 不確実性

次を確認し、本件に関係するものだけリスクにする。

- 要件の曖昧さ
- 技術的な未知
- 外部API
- データ移行
- 非機能
- セキュリティ制約
- チームの習熟
- 開発環境と検証環境
- 他システムとの依存

## リスクの項目

- リスクID
- 内容
- 発生条件
- 影響範囲
- 見積もりへの影響
- 対応方針
- `already_in_three_point`

三点の悲観値に含めたリスクは `already_in_three_point: true` にする。予備工数の対象にしない。

三点に含めない残留リスクだけを予備にする。予備には理由、`independent_of_three_point: true`、対象リスクIDが必要である。根拠のない一律係数は拒否される。

リスクが三点の外にあり、予備も無い場合、スクリプトは警告する。警告を消すために係数を発明しない。未対応であることを結果に残す。
