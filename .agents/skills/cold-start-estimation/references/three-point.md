# 三点見積もり

各算定可能項目に O、M、P を置く。

- O: 前提が成立し、大きな手戻りが無い場合
- M: 通常の確認と軽微な手戻りを含む場合
- P: その項目に書いたリスクが現実になる場合。想定外の大惨事まで含めない

PERT期待値は `(O + 4M + P) / 6`。スクリプトが計算する。保証値ではなく、Pは統計的な信頼上限でもない。

## 根拠が弱いとき

標準生産性が無い作業は、狭い三点にしない。次のどちらかにする。

- 幅の広い O、M、P を置き、`uncertainty: high`、`provisional: true`、`basis.kind: AI_ESTIMATE` とする
- 幅も置けない場合は `estimable: false` とし、未算定として残す

`AI_ESTIMATE` の説明には、何を見てその幅にしたかを書く。「経験上妥当」だけは不可。出典が無い値に `SOURCE` を付けない。

## 入力

工数は `"2"` や `"0.5"` のような十進文字列、または整数。JSONの浮動小数は拒否される。単位は依頼全体の `meta.effort_unit` と揃える。
