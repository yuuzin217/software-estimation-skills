この見積もりは保証値ではありません。PERT期待値は三点の加重平均であり、統計的な信頼区間でも、IPAやSIerが保証した値でもありません。

## 根拠

### 計算方法

PERT期待値 E = (O + 4M + P) / 6。期待値は保証値ではなく、悲観値は信頼区間の上限ではありません。
合計は丸める前の値を加算し、最後に一度だけ丸めます。
計算パッケージの版: 0.1.0

方式選択の方針（外部標準ではない）:
- 類似度の下限: 0.60
- historical を主方式にする最少件数: 3
- 規模按分に必要な工程の重なり: 0.50
- 規模外挿の上限: 有効実績の観測範囲から上下2倍
- これらは本ツールの方針であり、IPA等の公的基準ではない。

### 実績データ

読込 0 件、有効 0 件、類似度が下限以上 0 件、規模按分に使用 0 件。
規模外挿の評価: not_assessed。規模按分に使える実績が無いため、外挿範囲を評価できません。
実績見積もり: not_calculated。類似し、規模指標と工程が対応する実績が不足しています。

- IPAの統計は、条件が一致した照合に限って参照します。現代のクラウド開発やAI支援開発へ無条件には使いません。
