# 見積もり結果

この見積もりは保証値ではありません。PERT期待値は三点の加重平均であり、統計的な信頼区間でも、IPAやSIerが保証した値でもありません。

- 警告: 主方式の工数にはAIによる暫定推定が含まれます。精度が高い見積もりではありません。

## 基本情報

- 対象システム: 架空の社内申請システム
- 見積もり目的: 非機能要件を独立して見積もる
- 見積もり対象: 申請1種。監査、脆弱性診断、応答時間の目標がある
- 見積もり方式: 主方式 cold-start / 補助 none
- 方式を選んだ理由: 採用できる類似実績が無いため、cold-start を主方式にしました。
- 見積もり実施日: 2026-10-20
- 工数単位: 人日
- 1人日の時間: 未指定（換算しない）

申請1種。監査、脆弱性診断、応答時間の目標がある

### 前提条件

## 根拠

### 計算方法

PERT期待値 E = (O + 4M + P) / 6。期待値は保証値ではなく、悲観値は信頼区間の上限ではありません。
合計は丸める前の値を加算し、最後に一度だけ丸めます。
計算パッケージの版: 0.1.0

方式選択の方針（外部標準ではない）:
- 類似度の下限: 0.60
- historical を主方式にする最少件数: 3
- 規模按分に必要な工程の重なり: 0.50
- 規模外挿の上限: 有効実績の観測範囲から上下2倍
- これらは本ツールの方針であり、IPA等の公的基準ではない。

- 要件の分解と三点の幅は入力側の判断であり、計算式はその数値を検証・集計するだけです。
