# タスク管理ミニアプリ — 要件

## 機能要件
- F-001: タスクを登録・変更・削除できる。
- F-002: タスクの一覧を表示でき、完了／未完了で絞り込める。
- F-003: タスクに期限を設定できる。

## 非機能要件
- NF-001: パソコンとスマートフォン双方で操作できる。
- NF-002: 認証された利用者だけが自分のタスクを閲覧・編集できる。

## 対象外
- 有償課金
- 他ユーザーとのタスク共有

## 未確定事項
- 認証基盤と利用者登録の方式
- 対応ブラウザーとアクセシビリティ基準
- データ移行の有無

これは**見積もりワークフローを試すための架空の要件**であり、工数実績ではありません。
